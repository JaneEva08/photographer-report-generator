# Генератор отчётов фотографа для Google Sheets

Учебное приложение VPh02 для курса «Профессия вайб-кодер», модуль 9. Программа создаёт демонстрационные данные о съёмках за выбранный период и оформляет их в новой вкладке Google Таблицы: сводные показатели, детализация, формулы, статусы оплат и диаграмма.

## Возможности

- Python-модуль `GoogleSheets` для чтения и изменения ячеек, диапазонов и листов, форматирования, объединения ячеек и диаграмм.
- Tkinter-интерфейс: период, имя фотографа, выбор тематик, генерация отчёта и HTML-предпросмотр.
- Тематики, пакеты, доплаты, зоны выезда и статусы оплаты на синтетических данных.
- Пакетная отправка запросов форматирования, чтобы сократить обращения к API.
- 43 автотеста с поддельным Google API; тесты не используют реальные ключи.

## Запуск в Windows

Требуются Python 3.11+ и доступ к Google Sheets API.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

В Google Cloud включите Google Sheets API, создайте сервисный аккаунт и JSON-ключ. Добавьте `client_email` сервисного аккаунта в настройки доступа нужной таблицы с правом редактора. Сохраните JSON-ключ в этой папке как `service_account.json`; секретный файл не публикуйте.

В `.env` укажите ID таблицы:

```dotenv
GOOGLE_CREDENTIALS_PATH=service_account.json
SPREADSHEET_ID=ID_ТАБЛИЦЫ
PHOTOGRAPHER_NAME=Имя фотографа
```

Запустите приложение:

```powershell
python report_generator.py
```

Кнопка «Предпросмотр» работает локально без ключа Google. Чтобы проверить только тесты:

```powershell
pytest -q
```
